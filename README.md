# Welcome to Keploy's Demo Site!

This is the demo instruction site for Keploy, a platform that helps developers test their applications by recording and replaying their API requests and responses, with a sample Go application.

Steps to run build and run this page locally:
1. Clone the repo
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the development server
4. Open `http://localhost:3000` in your browser
